Décompresse le ZIP puis ouvre **le dossier entier** dans Antigravity, pas seulement `index.html`.

## Consignes pour un assistant de code

Lis d'abord `README.md`, `index.html`, `css/style.css` et `js/script.js`.
Garde le site responsive, le ton humain et les coordonnées existantes.
