Étape 1

Chiffrer un secret

Saisissez une phrase secrète maîtresse robuste (minimum 12 caractères). Collez vos identifiants, clés API ou notes dans la zone d'entrée, puis cliquez sur Chiffrer les données. Copiez le bloc généré ou téléchargez le fichier .crypt.

Étape 2

Déchiffrer un secret

Collez le bloc chiffré Base64 (ou le contenu de votre fichier .crypt ouvert avec un éditeur de texte) dans la zone d'entrée. Saisissez le même mot de passe maître, puis cliquez sur Déchiffrer les données.

Étape 3

Partager sans risque

Pour envoyer des accès à un tiers, transmettez le bloc chiffré par e-mail et communiquez le mot de passe maître par un canal séparé (SMS ou téléphone). Sans les deux éléments, le message reste illisible.

Étape 4

Effacer ses traces

Aucune donnée n'est enregistrée sur internet ni dans votre navigateur. Une fois votre opération terminée, cliquez sur Purger la mémoire. Le presse-papiers est automatiquement vidé 30 secondes après chaque copie.

Règle d'or Zero-Knowledge : Ni le serveur ni l'éditeur de cet outil ne connaissent votre mot de passe maître. Aucune fonction de « mot de passe oublié » n'existe : si vous perdez votre phrase secrète, vos fichiers .crypt sont définitivement irrécupérables.

Exécution 100 % côté client — Algorithmes standards NIST (AES-256-GCM / PBKDF2-HMAC-SHA256).
