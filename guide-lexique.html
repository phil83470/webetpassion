PILIER 1

Structure & Code : La Vitrine & Le Moteur

Tout ce que le visiteur voit à l’écran et ce qui fait tourner l’interactivité.

Front-End

Côté Client

La partie visible du site internet. Tout ce qui s’affiche à l’écran et avec lequel le visiteur interagit directement.

Exemple concret : Le design, les couleurs, les boutons et les formulaires que vous remplissez.

Back-End

Côté Serveur

Les coulisses invisibles du site. Gère les bases de données, la sécurité, les calculs et la logique serveur pure.

Exemple concret : L'enregistrement d'une commande, le traitement d'un paiement ou la vérification d'un mot de passe.

HTML

Le Squelette

Langage de balisage fondamental. Il structure et hiérarchise tout le contenu de vos pages.

Exemple concret : La balise <header> pour le haut de page, <h1> pour le titre principal.

CSS

L’Habillage

Feuilles de style. Gère la mise en page, l'esthétique visuelle, les couleurs, les marges et les polices.

Exemple concret : Définir un fond sombre, des boutons arrondis ou ajouter une ombre élégante.

JavaScript (JS)

Le Moteur

Programmation dynamique côté client. Apporte l'interactivité, le mouvement et la réactivité instantanée.

Exemple concret : Faire apparaître le menu hamburger au clic ou animer l'apparition d'un élément au défilement.

PHP

Affichage Dynamique

Langage serveur qui assemble et génère du code HTML sur mesure avant de transmettre la page au navigateur.

Exemple concret : Charger automatiquement le bon en-tête via include('header.php') sur toutes les pages.

Responsive Design

L’Adaptation

Capacité d'un site à s'adapter automatiquement à toutes les résolutions d'écrans (smartphone, tablette, PC).

Exemple concret : Passer d'une navigation horizontale sur ordinateur à un menu déroulant vertical sur mobile.
🌐

PILIER 2

Hébergement & Performance : L’Infrastructure

Le lieu où le site habite et les mécanismes qui assurent sa disponibilité.

Nom de Domaine

L'Adresse

L'adresse texte unique qui permet aux visiteurs de retrouver facilement votre site sur le réseau mondial.

Exemple concret : webetpassion.fr ou latelierdecesames.fr.

Hébergement Web

Le Terrain

Espace de stockage sécurisé sur un serveur physique distant connecté à Internet en continu 24h/24.

Exemple concret : Un compte d'hébergement chez un prestataire comme o2switch ou Infomaniak.

Racine du Document

Document Root

Le dossier exact sur le serveur où le nom de domaine va pointer pour chercher la page d'accueil.

Exemple concret : Le répertoire public_html/mon-site.fr.

cPanel

Tableau de Bord

Une interface visuelle en ligne permettant de gérer ses fichiers, ses adresses e-mails et ses bases de données.

Exemple concret : Accéder au Gestionnaire de Fichiers pour déposer une nouvelle page sans ligne de commande.

Le Cache

Mémoire Rapide

Sauvegarde temporaire des images et scripts dans le navigateur pour accélérer les visites ultérieures.

Astuce : Faire Ctrl + F5 pour forcer le navigateur à recharger la toute dernière version.

Erreur 404

Page Introuvable

Code d'erreur renvoyé par le serveur web lorsqu'un fichier demandé n'existe pas ou a été déplacé.

Exemple concret : Un lien pointant vers contact.html alors que le fichier s'appelle contact.php.

PILIER 3

Outils & Méthodes : L’Atelier

Comment les développeurs conçoivent, organisent et protègent votre site.

IDE vs CMS

Les Outils

L’IDE est le logiciel du développeur pour coder sur mesure (ex : VS Code). Le CMS permet d'administrer du contenu sans toucher au code (ex : WordPress).

Distinction : Le code sur mesure garantit légèreté et sécurité maximale ; le CMS offre une gestion autonome du contenu.

Git & GitHub

Version & Partage

Outil permettant de sauvegarder l'historique complet des modifications de code (véritable machine à remonter le temps).

Cas pratique : Permet de tester une nouveauté sans jamais risquer d'écraser la version fonctionnelle du site.

Arborescence

Organisation

L'organisation hiérarchique et logique des dossiers et fichiers composant un site web.

Exemple concret : Ranger les images dans un sous-dossier assets/ au même niveau que index.html.

Permissions (CHMOD)

Sécurité

Les règles de sécurité du système définissant qui a le droit de lire, modifier ou exécuter un fichier.

Exemple concret : Régler l'accès d'un fichier index.html sur le code 644 (lecture publique, écriture réservée).

Ancre HTML

Navigation Interne

Un lien spécifique qui amène directement le visiteur à un endroit précis de la même page sans rechargement.

Exemple concret : Un lien <a href="#services"> qui fait défiler la page jusqu'au bloc des prestations.

SEO & Optimisation

Visibilité

L'ensemble des techniques pour positionner naturellement un site dans les premiers résultats Google.

Exemple concret : Renseigner des balises <title> précises et intégrer des mots-clés stratégiques.

VISION D'ENSEMBLE

L’Anatomie d’un Projet Web

Comment l’Atelier (outils & méthodes), l’Infrastructure (serveur & données) et la Vitrine (rendu & code) collaborent ensemble pour donner vie à votre site internet :

1. L’Atelier

Conception & Code

Avec l’IDE (VS Code), Git et une arborescence soignée, le code HTML, CSS et JavaScript est rédigé, testé et sécurisé avec précision.

2. L’Infrastructure

Hébergement & Données

Le serveur héberge les fichiers à la racine (Document Root). cPanel gère les accès, PHP assemble les données et le cache accélère la distribution.

3. La Vitrine

Affichage & Visiteurs

Le nom de domaine amène le visiteur sur une interface fluide, responsive sur tous les écrans, optimisée pour le référencement SEO.
