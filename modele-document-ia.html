2. Objet du document

Le présent document définit le cadre général dans lequel Web & Passion peut utiliser des outils d'intelligence artificielle dans le cadre de ses prestations.

L'intelligence artificielle peut être utilisée comme outil d'assistance, d'analyse, de création, de rédaction, de développement ou d'optimisation.

Son utilisation ne constitue pas un remplacement du contrôle, de la réflexion et de la validation humaine.

3. Utilisations possibles de l'intelligence artificielle

Selon la nature du projet et les besoins du client, des outils d'intelligence artificielle peuvent notamment être utilisés pour :

  • la recherche et la structuration d'informations ;
  • la génération ou l'amélioration de textes ;
  • l'aide à la rédaction de contenus web ;
  • l'analyse et l'optimisation de contenus ;
  • l'aide à la conception de pages web ;
  • l'assistance au développement HTML, CSS ou JavaScript ;
  • l'analyse de code et la recherche d'erreurs ;
  • l'amélioration de l'expérience utilisateur ;
  • l'aide à la création de structures ou d'idées ;
  • l'optimisation SEO ;
  • la génération ou l'amélioration d'éléments graphiques lorsque cela est prévu dans le projet.

4. Contrôle humain

Les contenus ou éléments produits avec l'aide d'une intelligence artificielle ne sont pas considérés comme automatiquement définitifs.

Web & Passion conserve un contrôle humain sur les éléments intégrés dans les projets.

  • Les contenus peuvent être relus.
  • Les informations peuvent être vérifiées.
  • Les textes peuvent être corrigés ou réécrits.
  • Le code peut être contrôlé et adapté.
  • Les résultats générés peuvent être modifiés avant livraison.
Principe : l'IA constitue un outil d'assistance. La validation finale relève d'une intervention humaine.

5. Vérification des informations

Les outils d'intelligence artificielle peuvent produire des informations inexactes, incomplètes, obsolètes ou nécessitant une vérification complémentaire.

Lorsque la nature du projet le nécessite, Web & Passion peut effectuer des vérifications complémentaires à partir de sources appropriées.

Pour les informations particulièrement sensibles ou réglementées, une validation par une source officielle ou par un professionnel compétent peut être nécessaire.

6. Données, confidentialité et informations transmises

Web & Passion veille à limiter la transmission de données personnelles, confidentielles ou sensibles aux outils d'intelligence artificielle lorsque cette transmission n'est pas nécessaire à la réalisation de la prestation.

Lorsque l'utilisation d'un outil d'IA implique le traitement de données fournies par le client, la nature des informations concernées doit être prise en considération avant leur transmission.

  • Les données inutiles à la tâche ne doivent pas être transmises.
  • Les informations confidentielles doivent être limitées autant que possible.
  • Les données personnelles doivent être traitées avec les précautions appropriées.
  • Les informations sensibles ne doivent pas être transmises à un outil d'IA lorsque cela n'est pas nécessaire.
Important : les modalités précises de traitement des données personnelles sont également encadrées par la politique de confidentialité applicable au site ou au projet concerné.

7. Contenus générés ou assistés par IA

Lorsqu'un contenu est produit avec l'aide d'une intelligence artificielle, son intégration dans un projet dépend de sa pertinence, de sa qualité et des conditions applicables à l'outil utilisé.

Web & Passion peut modifier, adapter, combiner ou réécrire les éléments générés afin de les intégrer au projet du client.

Lorsque cela est nécessaire, les droits, licences ou conditions d'utilisation applicables aux outils et ressources utilisés doivent être vérifiés avant leur exploitation commerciale.

8. Limites de l'intelligence artificielle

L'intelligence artificielle ne garantit pas à elle seule l'exactitude, l'exhaustivité ou l'actualité d'un résultat.

Elle peut notamment produire :

  • des erreurs factuelles ;
  • des informations incomplètes ;
  • des interprétations incorrectes ;
  • du code nécessitant une correction ;
  • des contenus nécessitant une vérification humaine.

L'utilisation d'une IA ne dispense donc pas de procéder aux vérifications nécessaires avant publication, livraison ou utilisation professionnelle.

9. Transparence envers le client

Lorsque l'utilisation de l'intelligence artificielle constitue un élément significatif de la prestation, Web & Passion peut informer le client de cette utilisation.

Cette information peut notamment être précisée dans :

  • le devis ;
  • le bon de commande ;
  • les conditions contractuelles ;
  • ou tout autre document lié au projet.

10. Clause applicable aux prestations

Dans le cadre de certaines prestations, Web & Passion peut utiliser des outils d'intelligence artificielle comme assistance à la conception, à la rédaction, à l'analyse, au développement ou à l'optimisation.

Les éléments ainsi obtenus peuvent être vérifiés, corrigés, adaptés ou intégrés par Web & Passion selon les besoins du projet.

L'utilisation de l'intelligence artificielle ne constitue pas une garantie d'absence d'erreur et peut nécessiter une validation complémentaire lorsque la nature du contenu l'exige.

11. Évolution du document

Le présent document pourra être modifié afin de tenir compte de l'évolution :

  • des outils d'intelligence artificielle utilisés ;
  • des pratiques professionnelles ;
  • des exigences contractuelles ;
  • des règles applicables au traitement des données ;
  • du cadre juridique applicable.

La version applicable à un projet peut être précisée dans les documents contractuels correspondants.
